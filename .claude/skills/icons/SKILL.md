# Icons Skill

blökkli uses a build-time icon system that statically extracts icon references
from source code and bundles only the icons that are actually used.

## Icon Sources

### 1. Material Symbols (`bk_mdi_*`)

Icons from the `@material-symbols/svg-600` package (rounded variant). Referenced
by name with the `bk_mdi_` prefix.

**Naming convention**: Take the Material Symbols icon name (e.g. `arrow_right`)
and prefix it with `bk_mdi_`: `bk_mdi_arrow_right`. For filled variants, append
`-fill`: `bk_mdi_help-fill`.

**Example usage**:

```vue
<Icon name="bk_mdi_search" />
```

```ts
// In defineBlokkliFeature:
icon: 'bk_mdi_settings',
```

### 2. Custom SVG icons (no prefix)

SVG files in `src/runtime/editor/icons/svg/` are always included. They use the
filename (without extension) as the icon name.

**Available custom icons**:

```
arrow-right-thin  artboard      dock-window  duplicate
loader            logo          reusable     reusable-detach
robot             spinner       star         stars
tiktok            unstar        vimeo        window-maximize
window-minimize   youtube
```

**Example usage**:

```vue
<Icon name="artboard" />
```

### 3. Userland custom icons

Projects using blökkli can add their own icons by placing SVG files matching the
pattern `icon-blokkli-*.svg` anywhere in their source directory. These are
discovered automatically by the `IconCollector`.

## How Icon Extraction Works

### Runtime code (blökkli source)

1. `npm run material-icons` scans all `.vue` and `.ts` files in `src/runtime/`
   and `src/modules/` for strings matching the regex `/bk_mdi_[a-z0-9_-]+/g`
2. It generates `src/build/used-icons.ts` — a static list of all Material
   Symbols icons used in blökkli's own runtime code
3. This file is part of the published package, so it doesn't need to be
   regenerated by consumers

### Build template (Nuxt module build)

The template at `src/build/templates/definitions/icons.ts` runs at Nuxt build
time and combines:

- Icons from `src/build/used-icons.ts` (blökkli runtime)
- Icons referenced in `defineBlokkli()` definitions (`editor.icon` property)
- Icons referenced in block/global options (radios with `displayAs: 'icons'`)
- Icons referenced in `defineBlokkliFeature()` definitions
- Custom SVGs from `src/runtime/editor/icons/svg/`
- Userland `icon-blokkli-*.svg` files

It validates each `bk_mdi_*` name against the actual
`@material-symbols/svg-600/rounded/` package and imports matching icons as
`?raw` SVG strings.

## Adding a New Icon Reference

### In blökkli runtime code

1. Use the icon name string (e.g. `bk_mdi_favorite`) anywhere in the code — as a
   prop, variable, or string literal
2. Run `npm run material-icons` to regenerate `src/build/used-icons.ts`
3. The icon will be included in the next build

### In userland code (defineBlokkli, features, options)

Just reference the icon name. The build template extracts it automatically at
Nuxt build time — no manual step needed.

## Validation

The build validates icon names at build time via
`IconCollector.isValidIconName`. If an icon name doesn't exist in the Material
Symbols package or as a custom SVG, the build will warn about it.
