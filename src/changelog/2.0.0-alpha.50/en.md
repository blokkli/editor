### New Features

#### Swap block positions

Select two blocks and use the new "Swap block positions" action to exchange
their positions. This works across different fields, as long as both block types
are allowed in each other's field.

### Improvements

- Blocks with an editor option (e.g. chart data) now show the edit button even
  when regular editing is disabled. Clicking it opens the option editor
  directly.
