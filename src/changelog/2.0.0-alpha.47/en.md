### New Features

#### Block permissions

Administrators can now restrict which block types individual users are allowed
to create, edit, or delete. Restricted blocks are visually marked in the editor.

#### Fragments in block selector

When adding a block before or after a selected block, available fragments are
now listed directly in the selector by name. Clicking a fragment adds it
immediately without opening a separate dialog.

### Improvements

- The block selector now groups items into separate sections for blocks,
  fragments, and actions, making it easier to find the right entry.
- The block selector adjusts its height to the available viewport space,
  reducing unnecessary scrolling when it opens near the top of the screen.

### Fixes

- Fixed the analyze tooltip not being positioned and styled correctly.
- Fixed the tooltip transition playing with the wrong origin when the tooltip
  opens above the anchor.
- Fixed the add button tooltip staying visible while the block selector is open.
