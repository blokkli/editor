### New Features

#### Accept AI text changes paragraph by paragraph

When the AI assistant proposes changes to a longer text, you no longer have to
accept or reject the entire text: individual paragraphs or list items can now be
accepted or discarded selectively – by click or with the keyboard.

#### Validations in the page analysis

Validation errors are now shown directly in the page analysis – alongside the
other analysis results such as readability or accessibility. The separate
validations view is gone; in return, the page analysis is always available.

#### Validation errors when saving/publishing

If publishing fails because of validation errors, the dialog now shows the
specific problems so you can fix them right away.

#### Blocks linked in AI assistant answers

When the AI assistant refers to a block in its answers, its label now appears as
a clickable link that jumps directly to the block on the page. Previously, a
cryptic ID was sometimes shown instead.

### Improvements

- The color picker in the chart editor has been reworked: all colors and their
  shades are now presented as a clear palette.

### Fixes

- Clicking a page analysis highlight now reliably jumps to the affected spot,
  even when the sidebar is closed. Highlights are correctly reset when closing
  the page analysis.
- The AI assistant's text search now attributes text to the correct block when
  blocks are nested inside each other.
