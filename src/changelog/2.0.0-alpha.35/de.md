### Neue Funktionen

- **KI-Assistent**: Im Editor steht ein neues KI-gestütztes Assistentenpanel zur Verfügung, über das Inhaltselemente per Chat hinzugefügt, verschoben, gelöscht und umgeschrieben werden können – inklusive Planung, Gesprächsverlauf und Medienauswahl.
- **Block-Vorschau im «Hinzufügen»-Panel**: Beim Überfahren eines Blocktyps im Hinzufügen-Panel wird ein Tooltip mit einer Vorschau und Beschreibung angezeigt.
- **Vorlagenverwaltung**: Eine neue Verwaltungsansicht ermöglicht es, gespeicherte Vorlagen direkt im Editor umzubenennen und zu löschen.
- **Diagramme**: Ein neuer Diagramm-Blocktyp ist verfügbar, um interaktive Diagramme auf Seiten einzubetten.
- **Inhaltsverzeichnis**: Ein neues Inhaltsverzeichnis-Modul ist verfügbar.

### Verbesserungen

- Durch Halten von Strg und Klicken können nun mehrere Elemente gleichzeitig in der Medienbibliothek ausgewählt werden.
- Beim Ziehen werden Elemente jetzt präziser in der Grösse des verschobenen Blocks dargestellt.
- Ablagezonen verkleinern sich optisch, wenn sie nicht aktiv überfahren werden, was während des Ziehens für ein aufgeräumteres Layout sorgt.

### Fehlerbehebungen

- Lange Optionsbeschreibungen im Optionen-Tooltip werden nun korrekt dargestellt und laufen nicht mehr über.
- Die Hover-Erkennung bei überlappenden Blöcken berücksichtigt nun korrekt die Z-Index-Reihenfolge.
- Das Standardsymbol für Fragment-Blöcke wird nun korrekt angezeigt.
- Das Öffnen des KI-Assistenten über das Dropdown-Menü eines Blocks stellt kein vorheriges Gespräch mehr wieder her, sondern startet eine neue Unterhaltung.
