### Neue Funktionen

#### KI-Assistent

Im Editor steht ein neuer KI-Assistent zur Verfügung. Damit können Blöcke per
Chat hinzugefügt, verschoben, gelöscht und umgeschrieben werden – inklusive
Planung, Gesprächsverlauf und Medienauswahl.

#### Block-Vorschau im «Hinzufügen»-Panel

Beim Überfahren eines Blocktyps im Hinzufügen-Panel erscheint ein Tooltip mit
Vorschau und Beschreibung.

#### Vorlagenverwaltung

In einer neuen Verwaltungsansicht können gespeicherte Vorlagen direkt im Editor
umbenannt und gelöscht werden.

#### Diagramme

Ein neuer Diagramm-Blocktyp ist verfügbar, um interaktive Diagramme auf Seiten
einzubetten.

#### Inhaltsverzeichnis

Ein neues Inhaltsverzeichnis-Modul ist verfügbar.

### Verbesserungen

- Mit Strg+Klick können jetzt mehrere Elemente in der Medienbibliothek
  gleichzeitig ausgewählt werden.
- Beim Ziehen werden Elemente jetzt passender in der Grösse des verschobenen
  Blocks dargestellt.
- Ablagezonen werden kleiner dargestellt, wenn sie nicht aktiv überfahren
  werden, was beim Ziehen für ein aufgeräumteres Layout sorgt.

### Fehlerbehebungen

- Lange Optionsbeschreibungen im Optionen-Tooltip werden jetzt korrekt
  dargestellt und laufen nicht mehr über.
- Überlappende Blöcke reagieren jetzt korrekt auf Hover-Aktionen.
- Das Standardsymbol für Fragment-Blöcke wird jetzt korrekt angezeigt.
- Der KI-Assistent startet jetzt immer ein neues Gespräch, wenn er über das
  Dropdown-Menü eines Blocks geöffnet wird.
