### New Features

#### Edit and translate link texts

The text of a link field can now be edited directly on the page and is included
in automatic translation. The link target stays unchanged.

### Fixes

- The AI assistant sometimes worked with the displayed version of a text instead
  of the stored one. Saving could therefore change links or permanently keep
  automatically added notes.
- When only some sections of a suggestion were accepted, the resulting text
  could be saved incorrectly.
- When reviewing suggestions, the markers of several texts in the same block
  overlapped and could no longer be clicked individually. Such texts are now
  merged into a single marker.
