### New Features

#### Automatic text replacements

When editing text fields, common typographic patterns are now automatically replaced: straight double quotes ("...") become guillemets («...»), three dots (...) become an ellipsis (…), and double hyphens (--) become an en dash (–). Guillemet replacement is only active for German and French languages. All replacements can be undone with Ctrl+Z.

#### Undo/redo in text fields

Text fields now have a proper undo/redo history. Use Ctrl+Z to undo and Ctrl+Shift+Z or Ctrl+Y to redo.
