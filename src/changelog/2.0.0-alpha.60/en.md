### New Features

#### Notifications

A new notifications button has been added to the toolbar. A small badge shows
how many unread notifications you have. Opening the dropdown reveals a list of
relevant events — for example, when you have been mentioned in a comment, when a
comment has been resolved or when an edit has been approved.

Clicking a notification opens the related page directly in edit mode in a new
tab — and for comment mentions, jumps straight to the relevant comment.

All notifications can be marked as read with a single click.

#### The AI assistant understands page content better

The AI assistant can now read the complete page text — exactly what you see on
the page. This makes answers to questions like "What is this page about?",
"Summarize this page" or "Write an intro that matches the content" noticeably
more accurate.

### Improvements

#### View options in a dropdown

The view options (e.g. grid, anchor links, structure view) are now grouped into
a dropdown menu in the top toolbar.

#### Help in the app menu

The help dialog with the list of keyboard shortcuts has moved out of the right
sidebar and into the main menu.

#### Other improvements

- The toolbar with actions and options above a selected block can now be
  scrolled sideways when not all buttons fit.
- The preview thumbnails when the AI assistant picks media are larger.

### Fixes

- After applying or rejecting changes made by the AI assistant, page content
  occasionally appeared out of date — the display now updates reliably.
- Starting a new chat while confirming an AI action now cleanly cancels the
  pending action and starts the new chat fresh.
