### Neue Funktionen

#### Medienfelder direkt bearbeiten

Medienfelder (Bilder, Videos, etc.) auf Blöcken und auf der Seite selbst können
jetzt direkt im Editor bearbeitet werden. Neue Medien können aus der
Medienbibliothek hinzugefügt werden, einzelne Einträge können entfernt oder per
Drag & Drop umsortiert werden. Medien können auch aus einem Medienfeld heraus in
die Seite gezogen werden, um daraus einen neuen Block zu erstellen.

### Verbesserungen

#### Block mit Ctrl-Taste direkt bearbeiten

Mit gedrückter Ctrl-Taste (oder Cmd auf macOS) wird bei Doppelklick auf einen
Block das darunterliegende Medien- oder Textfeld ignoriert, sodass der Block
selbst bearbeitet werden kann.

#### Überarbeiteter Import-Dialog

Der Dialog zum Importieren bestehender Inhalte wurde überarbeitet. Inhalte
können jetzt über eine verbesserte Suche gefunden werden. Gibt es nur ein
importierbares Feld, wird die Feldauswahl neu ausgeblendet. Auf leeren Seiten
wird der Import-Dialog nicht mehr automatisch geöffnet, kann aber weiterhin
manuell aufgerufen werden. Das bisherige Verhalten lässt sich in den
Einstellungen wieder aktivieren.

#### Weitere Verbesserungen

- Der Editor lädt nun deutlich schneller. Selten verwendete Teile des Editors
  werden erst bei Bedarf geladen.
- Beim Laden des Editors wird Platz reserviert, sodass der Inhalt darunter nicht
  mehr springt, während der Editor geladen wird.

### Fehlerbehebungen

- Abgedockte Sidebar-Panels konnten in bestimmten Situationen ausserhalb des
  sichtbaren Bereichs landen und waren nicht mehr erreichbar. Die Positionen
  werden jetzt auf den sichtbaren Bereich beschränkt.
- Die Symbole in der responsiven Vorschau wurden nicht korrekt angezeigt.
- Die Vorschau von Fragment-Blöcken in der Auswahlliste werden wieder korrekt
  dargestellt.
