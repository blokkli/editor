### New Features

#### Comments

Comments are now full discussions:

- Reply to a comment to start a thread.
- Format comment text — bold, italic, lists, links, checklists and more.
- Mention teammates with "@" to direct a comment at someone.
- An avatar of the author now appears next to each comment.
- Edit or delete your own comments.
- Resolved comments now respect the "Show resolved" setting in the on-page
  overlay as well, matching the sidebar.
- Comments by since-deleted users no longer cause errors and show a placeholder
  instead.

#### Charts

Charts have been rebuilt for better quality and performance, with many new
capabilities:

- Import data from a CSV file — with a preview where you can transpose rows and
  columns, reorder them, choose which columns to import and filter out unwanted
  rows before confirming. A chart's data can also be exported back to CSV.
- A new "Advanced" chart type for fully custom charts.
- Number formatting: decimal places, locale, compact notation (e.g. "1.2M") and
  a custom prefix/suffix (e.g. "%" or "$"), with a live preview.
- Translate chart titles, labels, categories and footnotes per language.
- An optional category filter that shows a dropdown above the chart so viewers
  can display just one category (e.g. a single year) at a time.
- Automatic detection and formatting of date values in categories.
- A "Y-axis start value" option to set where the value axis begins.
- Charts no longer zoom by accident.

#### Block transfer

You can now export selected blocks to your clipboard and paste them into another
page – or even into another environment (e.g. from Live to Test).

When pasting, a summary shows what was imported and points out anything that
couldn't be transferred. This includes any content – such as images – that
doesn't exist in the target environment.

#### Superblökkli

- Edit a message you already sent and send it again; the assistant continues
  from your edited message.
- You can now rate an AI response without having to also write a comment.
- Administrators get a new area to browse all AI conversations and review the
  ratings users have given.

### Improvements

- The editor has been visually refreshed, with redesigned panels, dialogs and
  buttons.
- Automatic translation is now available from the block's actions menu, with a
  clearer translate icon, and the review view shows only the newly added text.

### Fixes

- Changed block options are now saved when an action (e.g. editing) is
  performed.
- Actions and fragments in the block selector are clickable again.
