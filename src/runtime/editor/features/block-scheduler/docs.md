## Action

"Manage schedule" is added to the block actions of selected blocks, while
editing (not while translating). It sets their "Publish on" and "Unpublish on"
dates.

## Languages

A date applies to the blocks in every language. On a page with more than one
translation, the dialog says so.

While a block's languages differ, each section lists their dates and, under
"Publish on", their status. "Set date for all languages" then shows the date
picker. A date that the user doesn't change isn't sent, so dates set per
language in the backend stay. See
[setBlockScheduleDate()](/adapter/setBlockScheduleDate#languages).
